    • ☑️ 防撤回 ​

    对方撤回消息后，机器人仍然能看到被撤回的原文。

    能做什么

    • 在聊天里发 /撤回（或 /rc）：当前会话最近 5 条撤回记录，带被撤回的原文。
    • /撤回 10：临时指定条数（最多 50）。
    • /撤回统计（或 /rcs）：本会话一共被撤回多少次、谁最常撤回、最近一次是什么时候。
    • 撤回提醒（配置页可开，默认关）：发现新的撤回时，机器人主动往那个会话发一条提醒并把原文带上。
    • 配置页还能调：启动时回填的历史条数、撤回扫描间隔、每轮重读条数。

    ⚠ 注意

    • 只覆盖「用户列表」里正在监听的会话；开启之前已经被撤回的救不回来（指令里会写明「原文没救回来」）。
    • 镜像与媒体备份放在 ~/Documents/wechatauto_recall/，媒体备份不会自动清理。
    • 「撤回提醒」会真的往会话里发消息，介意就别开。

    ☑️ 朋友圈查询 ​

    聊天里的人可以让机器人念朋友圈，也能知道谁赞了、评论了自己。

    能做什么

    • /朋友圈（或 /pyq）：发指令者最近 N 条动态 —— 时间、正文摘要、图/视频/赞/评论数量。
    • /朋友圈 老王：看指定昵称或备注的人最近动态；/朋友圈 10：临时指定条数。
    • /朋友圈互动（或 /pyqi）：谁赞了、谁评论了你的朋友圈（配置页可开，默认关）。
    • 朋友圈监听（配置页可开，默认关）：监听对象发了新动态时，机器人下次跟对方聊天会知道这件事。

    ⚠ 注意

    • 这些都只读本机 sns.db、不打开朋友圈界面；只能读到已经同步到本机的动态。
    • 可见范围以本机微信权限为准：三天可见、分组可见、屏蔽都不会被绕过。
    • 点赞和评论只给数量、不给文字（微信画在自绘区域里，抓不到文本）。

    ❓ 常见问题 ​

    WeChatBot启动报错 ​

    • 尝试不以管理员身份运行桌面快捷方式《启动机器人》
    • 你的系统版本过低或精简阉割了支持的环境
    • 更换网络环境或者重启之后后再次启动WeChatBot

    Python未安装或启动报错

    • 完全卸载Python重新安装。

    • 安装时将python添加进系统path
    • 网吧可能无法安装Python更换网吧或者在家使用。

    • 安装Python重新选择其他盘符安装。

    • 启动器已不再限制 Python 版本（3.9–3.12 的旧限制已移除），但部分定制依赖包是按 Python 3.9–3.12 提供的，建议仍用这个范围。
